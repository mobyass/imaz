Installer l'app

ARMAZ sur ton téléphone

Ajoute ARMAZ à ton écran d'accueil.

Gratuit · Rapide · Immédiat

ARMAZ fonctionne déjà sur ton téléphone depuis le navigateur. Il suffit de l'épingler sur ton écran d'accueil — tu l'ouvriras comme n'importe quelle autre app.

Utilise Safari pour installer ARMAZ sur iPhone.
1
Ouvre ARMAZ dans Safari
Si tu es dans une autre app, appuie sur « Ouvrir dans Safari ».
2
Appuie sur le bouton Partager ou les trois petits points
Selon ta version de Safari : appuie directement sur le bouton Partager, ou sur les trois petits points puis sur « Partager ».
3
Fais défiler le menu vers le bas
Cherche l'option « Sur l'écran d'accueil ».
4
Appuie sur « Sur l'écran d'accueil »
Le nom ARMAZ sera déjà rempli.
5
Appuie sur « Ajouter »
ARMAZ apparaît sur ton écran d'accueil comme une vraie app.
Utilise Google Chrome pour installer ARMAZ sur Android.
1
Ouvre ARMAZ dans Chrome
Si tu es dans une autre app, copie le lien et colle-le dans Chrome.
2
Appuie sur ⋮ en haut à droite
Les 3 petits points en haut à droite ouvrent le menu de Chrome.
3
Appuie sur « Installer l'application »
Peut aussi s'appeler « Ajouter à l'écran d'accueil » selon ton téléphone.
4
Confirme avec « Installer »
L'icône ARMAZ rejoint tes autres applications.
Tu peux aussi utiliser ARMAZ directement depuis ton navigateur, sans rien installer.
